# spotify-sql-analysis
SQL analysis project using Spotify streaming dataset

## Dataset

Spotify streaming dataset used for SQL analysis and Tableau visualization.
## Overview
This project analyzes Spotify streaming data using SQL to uncover trends in artist popularity, song performance, and streaming behavior.

## Objectives
- Identify top streamed songs
- Analyze artist performance
- Explore streaming trends
- Practice SQL querying and aggregation

## SQL Techniques Used
- SELECT statements
- WHERE filtering
- GROUP BY aggregation
- ORDER BY sorting
- Aggregate functions
- LIMIT usage

## Project Structure
- spotify_analysis.sql → Contains all SQL queries
- spproject.csv → Dataset used for analysis

## Sample Insights
- The Weeknd appeared among the top streamed artists
- Certain songs consistently dominated streaming counts
- Streaming trends increased significantly in recent years
